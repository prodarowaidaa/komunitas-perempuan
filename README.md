# Komunitas Perempuan 🌷

Ruang perencanaan komunitas perempuan untuk berdaya, berkarya, dan bertumbuh bersama.

> Tempat untuk hadir sebagai diri sendiri, mencoba hal baru, dan bermekaran dengan ritme masing-masing.

**Status: tahap perencanaan. Nama komunitas belum ditentukan.** “Komunitas Perempuan” adalah nama proyek sementara, bukan nama resmi.

## Tentang komunitas

Kami ingin membangun ruang yang hangat bagi perempuan dari semua latar belakang untuk saling mengenal, belajar, dan mendukung. Setiap perempuan boleh datang dengan perjalanan yang berbeda, tanpa tuntutan harus sempurna atau selalu produktif.

Komunitas ini berupaya menciptakan suasana aman melalui kesepakatan bersama, penghormatan terhadap batas pribadi, dan pengelolaan keluhan. Kenyamanan perlu dirawat bersama.

## Tiga pilar — rancangan awal

| Pilar | Tujuan | Contoh kegiatan |
| --- | --- | --- |
| Berdaya | Mengenali potensi dan berani mengambil langkah. | Berbagi keterampilan dan pengalaman karier. |
| Berkarya | Mencoba dan membuat sesuatu tanpa harus sempurna. | Merajut, menulis, fotografi, dan proyek bersama. |
| Bertumbuh | Belajar dan membangun pertemanan yang suportif. | Teman belajar dan refleksi ringan. |

“Bermekaran” menjadi inspirasi: setiap perempuan punya waktu dan cara tumbuh sendiri.

## Cara menggunakan proyek ini di GitHub

- **Code**: tempat membaca semua dokumen. Klik nama file untuk membukanya.
- **Edit / ikon pensil**: mengubah isi dokumen.
- **Commit changes**: menyimpan perubahan beserta catatan singkat, misalnya “Menentukan format pertemuan pertama”.
- **History**: melihat riwayat perubahan pada file.
- Kotak `- [ ]` di dokumen adalah tugas yang belum selesai; ubah menjadi `- [x]` jika sudah dikerjakan.

Dokumen ini menggunakan Markdown: teks biasa dengan tanda sederhana untuk judul, tabel, tautan, dan daftar.
